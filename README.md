# CS50 – Portfólio de Estudos
Este repositório contém todos os exercícios, projetos e laboratórios realizados no curso CS50: Introduction to Computer Science da Harvard University, versão 2025. O curso oferece uma introdução abrangente à ciência da computação e à arte da programação, abordando conceitos fundamentais e práticas essenciais.

## Sobre o Curso
O CS50 é um curso introdutório de ciência da computação que ensina os alunos a pensar de forma algorítmica e a resolver problemas de maneira eficiente. Os tópicos abordados incluem:
- Pensamento computacional
- Abstração
- Algoritmos
- Estruturas de dados
- Encapsulamento
- Gerenciamento de recursos
- Segurança
- Engenharia de software
- Desenvolvimento web
## As linguagens de programação utilizadas no curso são:
- C: para entender os fundamentos da programação e o funcionamento interno dos computadores.
- Python: para desenvolver aplicações de forma mais eficiente e com maior abstração.
- SQL: para manipulação e gerenciamento de bancos de dados relacionais.
- HTML, CSS e JavaScript: para desenvolvimento web front-end e back-end.

Os conjuntos de problemas (problem sets) são inspirados em áreas como artes, ciências humanas, ciências sociais e ciências naturais, proporcionando uma aplicação prática dos conceitos aprendidos.

## Tecnologias e Linguagens
- Linguagens de Programação: C, Python, JavaScript
- Desenvolvimento Web: HTML, CSS, Flask
- Banco de Dados: SQLite3
- Controle de Versão: Git & GitHub
